# 形体与网格

在灰模、主体细化、修改器或网格清理阶段读取。物件身份与交付范围遵循[物件清单](../manifest.md)，各阶段的证据要求遵循[制作流程](../workflow.md)。

## 从轮廓到结构

先用真实单位建立房间边界和主要物件的尺寸关系，再按照片中的外轮廓、厚度、开口和部件连接细化。构造方法按形状选择：

| 形状 | 适合的构造 |
|---|---|
| 平面板件、框体、箱体 | 平面或盒体，挤出、内插、实体化、局部倒角 |
| 杯、罐、瓶等旋转体 | 可编辑截面旋转；分配足够分段保持外轮廓 |
| 管、线、弯曲把手 | 曲线路径与截面扫掠；检查转弯处厚度和端部 |
| 对称物件 | 半边网格与 Mirror，检查中线合并 |
| 明确数量的重复结构 | Array 或共享网格的独立对象，具体选择见[场景装配](scene-assembly.md) |
| 非规则轮廓与局部连接 | 直接网格或 `bmesh`，按轮廓变化布置顶点 |

大形正确后补接缝、凹槽、支撑件和接触细节。细分密度以目标近看距离的轮廓与反射连续性为依据。

## 修改器与尺寸

Blender 修改器从列表上方向下求值。先处理对称和重复，再依据构造决定厚度与布尔顺序；需要磨圆布尔切口时，将 Bevel 放在 Boolean 后面。Weighted Normal 与平滑设置服务于可见着色结果；Subdivision 用在边线足以支撑形体的位置。

布尔前统一操作对象的尺度，刀具体单独管理。倒角宽度与物件实际厚度、参考可见边缘匹配。用局部权重或角度控制需要倒角的边，检查薄板是否因倒角夹紧而丢失轮廓。

保留有价值的构造参数用于修正，在交付求值前保存构造检查点。修改影响多个共享网格用户时，先决定所有实例一起改，还是给目标对象建立独立 data。

## 网格检查

检查求值后的几何，核对外法线、零面积面、重复面、孤立顶点、交叠和尺寸。合并距离按目标最小结构选择；需要保留的接缝和分离面岛保持原样。静态平面可保留可正确三角化的多边形；曲面和细分区域以稳定着色为准。

可移动物件的交付整理见[场景装配](scene-assembly.md)，表面坐标进入 [UV](uv.md)，结果使用[验收](qa.md)复查。
