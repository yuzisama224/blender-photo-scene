# UV 与纹理坐标

物件需要图像贴图、烘焙或可移植材质时读取。几何变化较大时，先完成影响展开的主要形体。

## 展开选择

| 表面 | 起点 |
|---|---|
| 箱体、平面构件 | 面投影或沿构造缝展开 |
| 容器与旋转体 | 侧面纵缝，口沿、内壁、底部分区 |
| 连续条带 | Follow Active Quads 或按路径建立连续坐标 |
| 非规则曲面 | 根据曲率和可见区域布置缝线，再展开 |

缝线优先沿构造边、底部或参考中低关注区域。可移动物件的所有必要表面都有对应坐标，正面贴图、侧面和背面各自覆盖正确。

## 密度与打包

纹理密度按实际表面长度与分配到的像素数计算。例如，2 m 的边占据 2048 px 贴图的半幅，其该方向密度为 512 px/m。相邻且同样重要的表面保持相近密度，近看细节依据目标画面分配更多面积。

UV 岛的间距以输出分辨率、烘焙扩边和纹理缩小采样为依据。共享图集时先定义物件各自区域，再打包；检查最小使用尺寸下的颜色串边和纹理模糊。

可重复图案允许明确的平铺或重叠 UV；独特标签、污渍和烘焙区域使用对应独立坐标。需要独立光照 UV 或 UDIM 时，以交付渲染器实际支持和用途决定布局。

## 检查

用格子纹理检查伸缩和接缝，再使用最终图像确认标签方向、纹理尺度和侧背底覆盖。修改几何、合并零件与导出后再次检查 UV 层和材质索引。贴图生成进入[纹理](texture.md)。
