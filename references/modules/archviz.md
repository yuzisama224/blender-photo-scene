# 建筑与室内

照片中包含房间、建筑或固定空间结构时读取。照片相机求解见[相机](camera.md)。

## 空间约束

选取用户尺寸、可辨认标准物件或已确认结构作为尺度依据，在清单中记录测量与推估。以墙面交线、地面、台面和门窗边框建立主平面，先锁定空间宽深高关系，再细分柜体或装饰结构。

使用独立的墙、地、顶、固定柜体等构造范围。结构厚度与开口深度共同决定投影、阴影和遮挡；在相机视角和空间检查视角都确认这些关系。基准面建立后，按照照片调整模块尺寸与间隙。

## 可见细节

| 区域 | 细化重点 |
|---|---|
| 柜体、抽屉、门板 | 分缝、厚度、拉手连接、台面下沿与接触阴影 |
| 门窗 | 玻璃厚度、框体截面、窗台深度、密封与相邻墙面关系 |
| 台面与地面 | 边缘倒角、材质尺度、接缝、固定物件的接触关系 |
| 金属或玻璃装置 | 准确截面、支撑与安装点、反射能够显示的边缘 |

细节深度来自参考中的结构证据；近看区域需要几何轮廓支撑，表面微纹理交给材质或贴图。移动范围会露出的固定空间表面按交付观察范围补齐。

## 材质与照明

先按[材质](materials.md)区分涂层、裸金属、木材、玻璃和织物，再设置[照明](lighting.md)。窗光、室内灯具和环境反弹共同形成室内明暗；匹配可见光源方向、阴影软硬与白平衡。

照片视角保持为比对相机；额外空间视角用于检查厚度、结构和可移动物件被移开后的表面。整体与物件证据分开按[渲染](rendering.md)生成。
