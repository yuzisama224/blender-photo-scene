# 日常物件

家具、容器、工具、电器和独立摆件细化时读取。照片中的物件清单决定数量、种类和摆放。

## 单件制作

逐件确认相对尺寸、轮廓、材料分区、支撑方式和可见细节。优先使用物件在原照片中的局部区域；清晰度不足时记录可确认的形体与合理补全范围。

| 物件结构 | 需要检查的形体 |
|---|---|
| 容器 | 外截面、口沿、壁厚、内腔、底部与握持结构 |
| 器具 | 主体厚度、操作部件、安装点、开孔和支撑 |
| 家具 | 承重路径、腿脚接触、板厚、转角和连接件 |
| 柔性或有机物品 | 大轮廓、重力形态和接触区域，再按参考补局部变化 |

造型分为主轮廓、次级结构和表面细节。用倒角、真实厚度和截面变化表达物件完成度；细节密度与交付近看距离相匹配。

## 移动后的完整性

可移动物件具备完整的侧面、背面、底部以及移动后可见的内表面。照片未提供的结构依据同类物件构造合理补全，并在[清单](../manifest.md)中记录推估依据。物件原点放在适合整体移动和旋转的位置，稳定接触面应能重新放回原位置。

制作中可分开构造主体、把手、标签等零件。交付前按[场景装配](scene-assembly.md)整理为该物件的一个 MESH，保留需要的面岛、UV 和多材质。真实外轮廓由几何表达；小字、图案与磨损可使用贴图。

结合原照片局部、制作视口和代表近景，确认比例、辨识细节、部件连接、着色与表面覆盖；有具体疑点时补充对应视角。结果进入 [UV](uv.md)、[材质](materials.md)和[验收](qa.md)。
