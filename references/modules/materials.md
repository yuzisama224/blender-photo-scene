# 材质

几何形体已经成立、需要区分真实表面时读取。贴图坐标和烘焙分别见 [UV](uv.md)与[纹理](texture.md)。

## 表面与参数

先把照片中的高光、阴影与物件固有颜色区分开。在已匹配的照明下调整 Principled BSDF，按当前 Blender 版本读取实际输入插槽。

| 表面 | 参数起点与检查方式 |
|---|---|
| 裸金属 | Metallic 接近 1；通过粗糙度和高光宽度判断抛光或拉丝 |
| 涂漆金属、塑料 | 涂层处按非金属处理；检查高光、底色和涂层边界 |
| 木材 | 纹理尺度与纹理方向沿真实构件；粗糙度表现油饰或原木 |
| 陶瓷 | 非金属表面，釉面通过粗糙度和适量涂层表现 |
| 玻璃 | Transmission 与 IOR 配合几何厚度；检查边缘、内外表面与背景透射 |
| 织物 | 较高粗糙度与合适 Sheen，纹理尺度匹配可见纤维 |

共享基础材质用于相同表面；需要独立颜色或粗糙度的物件使用明确的材质变体。单一 MESH 内可按面分配多个材质槽。

## 微表面

用纹理、Noise、ColorRamp 或有物理依据的遮罩控制细微粗糙度、凹凸和磨损。凹凸幅度用真实尺度校准，轮廓和较大结构仍由几何承担。磨损的位置与照片、接触边和使用方式一致。

纹理坐标优先绑定物件自身或 UV，使物件移动时表面跟随。使用外部映射对象时，检查其是否随交付保存并保持预期关系；需要可移植交付时按[纹理](texture.md)烘焙。

## 表面验收

在固定照片相机下比较材料分区、明度、粗糙度与反射；单件视图检查侧背底的覆盖、接缝和法线。透明物件还应在目标渲染器和导出回读后检查。把颜色调整、灯光调整和几何修正分别用于对应问题。
