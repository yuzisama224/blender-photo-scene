# 照明

场景结构和照片相机已足够稳定、需要匹配明暗和材质表现时读取。

## 从照片确定光源

根据投影方向、高光位置、阴影软硬和可见灯具确定主光方向与光源面积。先匹配主光，再补环境反弹和其他可解释光源。

| 光源证据 | Blender 起点 |
|---|---|
| 窗口或大面积柔光 | Area 或合适的环境光，匹配位置、方向和尺寸 |
| 平行而清晰的太阳影 | Sun，调整方向和角直径 |
| 局部灯泡 | Point 或按灯具构造设置光源 |
| 定向灯束 | Spot，核对锥角与照射区域 |

已有且授权使用的 HDRI 可作为环境，先旋转明亮方向，再调强度。可见发光面与实际照明分别检查，确保灯具辨识度和邻近表面亮度都合理。

## 调整顺序

固定[相机](camera.md)及当前色彩管理设置，用灰材质或统一粗糙度检查主光和阴影。光线关系稳定后恢复最终材质，逐项调整曝光、白平衡和局部光源。

明暗问题按原因修正：阴影方向对应灯位，阴影软硬对应光源尺寸，整体曝光对应色彩管理，反射过宽或过窄对应材质与光源共同检查。物件接触阴影用于检查落地关系。

## 可移动场景

灯光与世界按场景组织，交付物件表面保持能随物件移动的材质坐标。移动物件时，观察新增暴露面、阴影和透明表面是否仍成立。便携格式对灯光和复杂效果的支持由[导出](export.md)验证。

照片比对使用场景自身光照；单件结构证据的中性照明由[渲染](rendering.md)单独处理。
