# Geometry Nodes

明确重复结构、按曲线生成形体或需要反复调整参数时读取。物件清单决定最终数量、位置与独立对象范围。

## 合适的节点结构

| 需求 | 结构 |
|---|---|
| 明确位置的重复物件 | 显式点位置与方向 → Instance on Points |
| 管线或截面连续构件 | 输入曲线 → 按需要重采样 → Curve to Mesh → 材质 |
| 模块化空间构件 | 已确认尺寸与数量 → 实例布局 → 局部开口与材质分区 |
| 参考支持的自然分布 | 明确区域与数量规则 → 分布 → 有界随机变化 |

节点输入只暴露需要迭代的尺寸、数量和变化参数。使用随机行为时保存 seed，使同一参数得到可比较的输出。先检查当前 Blender 的节点类型、插槽和组接口，再建立连接。

## 物件边界

制作中用实例降低重复几何成本，交付时把清单中的每件物品落实为独立 MESH 对象。`Realize Instances` 将实例转为几何；单个节点宿主上的多个物品还需按身份建立各自对象。

形状相同的物品可共享网格 data 并各有变换。一个物品内部的重复细节可以固化到该物品网格，其不同材质、UV 与面岛保留。整理方法见[场景装配](scene-assembly.md)。

## 参数检查

检查实际需要的参数范围：最小厚度、最大尺寸、重复间距、转角和数量。确认曲线接头、端部、实例方向和材质分配在这些范围中成立。记录求值后的面数与物件数量，使用[验收](qa.md)验证结果。

重复构建与参数管理见[程序化建模](procedural.md)。
