# 纹理与烘焙

制作标签、图集、PBR 图像或将复杂材质转成可移植贴图时读取。

## 图像语义

| 图像 | 数据处理 |
|---|---|
| Base Color、彩色 Emission | 作为颜色图像读取，通常使用 sRGB |
| Roughness、Metallic、AO、Height、Normal | 作为数值数据读取，使用 Non-Color；Normal 通过法线贴图节点解释 |
| 通道打包 | 按目标材质定义接线；常见 ORM 为 R=AO、G=Roughness、B=Metallic |

可移动物件的材质应能在位置和光照变化后继续使用。图像底色表达表面颜色；原照片中的投影、背景和遮挡按表面语义处理。照片局部可用于颜色、图案和细节参考，其透视与照明需要与物件表面坐标相容。

## 烘焙步骤

先准备带 UV 的目标网格与来源表面。在当前 Blender 烘焙方式要求的位置设置目标图像，并明确源、目标和选中范围。高低模烘焙采用适合物件尺度的 cage 或射线距离，使射线覆盖要保留的细节并避开其他物件。

先烘焙一块代表区域，检查正常细节、凹槽与薄片，再完成全图。扩边宽度与目标分辨率、UV 间距相配合；法线贴图的切线空间和方向在交付渲染器中核对。

| 可见问题 | 优先核查 |
|---|---|
| 局部黑斑或跳变 | 源/目标法线、交叠表面、射线覆盖与目标图像 |
| 接缝 | UV 岛间距、扩边、法线一致性和 cage |
| 细节变糊 | 对应区域纹理密度、实际分辨率与缩小采样 |
| 移动物件后图案滑动 | UV 或映射坐标对物件的绑定关系 |

## 交付覆盖

贴图文件保存到本次资产目录并在源文件中正确引用或打包。采用 GLB 时检查图像已随导出携带；按[导出](export.md)回读验证材质连线、通道、透明度和最终外观。共享图集允许跨物件复用，每件仍保持独立对象身份。
