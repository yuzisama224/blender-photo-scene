# 照片场景制作流程

制作任务自动推进范围内的建模、免费素材查询与导出。软件和依赖安装遵循 [执行约定](modules/execution.md) 中的安装确认；阶段检查与复查范围遵循 [验收](modules/qa.md)。及时报告已有证据和待解决的具体差距。

## 1. 照片分析与制作范围

实际打开输入照片，逐区识别空间平面、固定设施和可辨认小物品。观察物品相互遮挡、接触位置、透视线、材质区域和光源方向。细小到无法识别的部分记录其可见形态；只有身份会显著改变结果时才询问。

建立 [物品清单](manifest.md)，确定最近查看距离、用户尺寸依据、交付目录和照片匹配相机。采用清单定义的独立任务场景，保留已有内容及构造检查点。默认写实和可近看，网格密度服务于轮廓与曲面质量。场景说明分别记录照片可证实的内容和需要推估的深度、尺度与隐藏面。

完成证据：物品清单覆盖已识别内容，固定与可移动类别明确，原图已查看，关键推估有文字记录。

## 2. 相机与灰模

根据主平面和消失线匹配相机位置、朝向、焦距、图像比例及必要的镜头位移，再放置房间、固定设施与物品占位。透视照片使用透视相机；裁剪、超广角或明显镜头畸变在分析中说明。

用固定照片相机生成一张快速预览，与同比缩放到相同尺寸的参考图对照主要轮廓、台面边缘、物品中心和遮挡关系。修正相机或上游尺度之后更新这张预览。物品数量、位置、比例和空间关系检查通过后保存灰模检查点，进入细化。

## 3. 场景与物品细化

按清单逐件制作主形、次形、真实厚度、倒角与部件接合。优先处理轮廓和近景能看见的结构，再制作包装、标签和表面纹理。每件可移动物品具有可独立观察的侧背底，移开后露出的场景结构也完整。

允许查询免费且许可证清楚的公开模型、纹理和 HDRI。素材的形态和比例应匹配照片；仅在匹配后导入，并登记来源和署名。物品几何可由现有模型精修或自行建模。不可读的标签只重现可辨认的色块、位置与视觉结构，在场景说明注明不确定内容。

依照清单组织单一网格移动单位，设置稳定 ID、原点和独立变换。构建脚本按稳定 ID 更新当前任务物品；重跑既有步骤时应定位现有对象。

制作时在视口检查各物品的轮廓、连接、厚度和隐藏面；阶段结束保存代表性近景及形体检查点。共享相同几何和材质的重复物品复用代表件证据，各自的数量与摆放由整场预览和清单检查覆盖。有具体疑点时补充对应物品视角。

## 4. 材质与灯光

以真实材质分区设置 UV、颜色、粗糙度、金属度、透明度和尺度正确的纹理。材质优先使用可转移的 Principled BSDF 与图像纹理；程序纹理需要转换或烘焙为 GLB 能表达的贴图。

整室对照始终使用照片匹配相机。先通过总览和代表近景判断；需要定位轮廓或位置差异时使用局部遮罩，并确认同一物品、同一比较方式。几何修正依据轮廓和结构证据；外观修正依据材质和光照证据。

形体与材质检查复用仍反映当前结果的近景。视口或现有图像不足以判断复杂接合、隐藏面或透明表面时，再为对应物品生成独立视图；整室照片相似度由原场景相机验证。

## 5. 完整移动与导出

先保存作者 `.blend`，按 [工具入口](scripts.md) 运行 `export_scene.py --report …`。导出器集中执行一次清单、网格及全部可移动物品的平移、旋转、还原验证，保存作者报告作为回读基准，通过后导出登记物品并保留 ID。网格、法线或 UV 有具体异常时使用 `inspect_asset.py` 诊断。

在新进程中对 GLB 运行一次 `verify_scene.py`，使用导出时保存的作者报告核对物品数量、身份、尺寸、变换、材质分区及独立移动。查看回读总览，纹理、透明或复杂材质的疑点补充近景。技术报告和视觉证据确认后进入交付。

Blender 工程打包引用图像，保留作者相机、材质、灯光和可编辑几何。GLB 是可转移的物品场景，照片展示效果以 Blender 工程和对应渲染为依据。

## 6. 修正与交付状态

各阶段只针对已发现且影响要求的差距修正，按影响范围复查；当前要求已有充分证据后进入下一阶段或交付。相同问题反复修正仍未解决时，重写只描述目标形态的局部规格，再重建对应物品。输入限制或环境错误导致无法继续时保存当前工程，列明需要补充的信息和仍未达到的要求。

最终用简短验收记录给出照片视角匹配、物品覆盖和完整性、近景几何与材质、完整独立移动、导出回读的结论、异常及证据路径；完整逐件数据保留在 JSON 报告中。同一份有效证据可支持多项结论，视觉结论注明实际观察或抽查范围。

交付按场景产品名命名的工程、GLB、构建脚本、预览和细节图、物品与素材清单、中文验收记录。最终回复提供可点击路径并说明仍需用户实物尺寸或补充视角确认的部分。
